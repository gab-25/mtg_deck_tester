{% comment %} Zoom-modal fragment served over HTMX and swapped into #card-image-modal-container on the deck view. It's a full-screen CSS overlay (no inline JS). A double-faced card ships both faces here at once; a hidden checkbox and the `.card-face` rules in styles.css decide which one is visible, so flipping costs no request. Closing: the backdrop and the Close button each hx-get this same endpoint with no url, which returns an empty body and so clears the container. The backdrop's trigger is filtered to `target:#card-image-modal` on purpose — clicks bubble, so without the filter every click inside the card (the Flip label included) would close the modal too. Close needs its own hx-get rather than a second filter, because clicking its icon makes the , not the button, the event target. {% endcomment %}
